# 盐抑制餐厨垃圾高温厌氧发酵产氢及镍/水热炭解抑制：分析与绘图代码

本仓库包含论文中理化数据处理、统计检验和全部图件的绘制脚本。原始实验数据可应合理要求向通讯作者索取。

## 运行环境

- Python 3.13
- 依赖见 `requirements.txt`：`pip install -r requirements.txt`
- 图件字体为 Times New Roman（Windows 自带；其他系统需另行安装）

## 目录约定

脚本放在项目根目录下的 `代码/` 文件夹中，所有路径都相对于项目根目录（`common.py` 中的 `ROOT`）：

| 位置 | 内容 |
|---|---|
| 根目录 `*.xlsx` | 原始实验记录（产氢、VFA、碳水、蛋白） |
| `16S/平台导出/` | 16S α 多样性指数表（测序平台导出） |
| `16S/16S_属水平组均值.csv` | 16S 属水平组均值相对丰度（%） |
| `宏基因组/平台导出/` | 宏基因组 α 多样性指数表 |
| `宏基因组/物种与功能差异分析/LEFSe差异辨别分析_细菌/` | LEfSe 结果表（平台导出） |
| `图表/Fig2/Fig2A_PCoA坐标.csv` | 16S PCoA 样本坐标 |
| `图表/FigS1_异常平行/MG_*.csv` | 宏基因组 PCoA 样本坐标与各样本属组成 |

## 主要处理说明

- **产氢量**：盐梯度实验每次测定后放气，累积产氢量为各次之和；解抑制实验不放气，以顶空累积量计。
- **碳水与蛋白**：测定时样品稀释 4 倍，脚本中已乘回稀释倍数。
- **产氢动力学**：修正 Gompertz 模型（`common.fit_gompertz`），后期出现耗氢的组仅拟合至累积产氢峰值。
- **解抑制作用**：对 ln(H₂) 做 2 × 2 双因素方差分析（添加剂 × NaCl），交互项显著视为特异性缓解（`common.twoway_interaction_p`）。
- **异常样本**：解抑制实验对照组中同批配制的 1 组测气瓶与取样瓶（A0-1 / A0_1）在主要分析中剔除，保留全部样本的结果由 `08` 输出。
- **测气瓶与取样瓶**：每个处理 3 瓶测气、3 瓶取样，二者为不同血清瓶；产氢量与菌群的关联分析以组均值进行。
